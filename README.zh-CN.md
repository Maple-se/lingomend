# LingoMend

先写你会的，再学你不会的。

LingoMend 是一款轻量的 macOS 英文表达助手。保留现有输入法，先自己写英文，遇到不会的表达可以用中文补缺，再按快捷键请求帮助。它结合当前句子或选区补全表达、纠正必要的英文问题，保留你的事实、观点和语气；也可以按需解释选中的英文词句在上下文中的含义。

## 功能

目前为开发版本，各编辑器的兼容程度不同，微信文本采集暂不支持。版本号以 [App/Info.plist](App/Info.plist) 为准。

- **⌃⌥L（Control-Option-L）**：对完整当前句或明确选中的词句、短段落提供建议。补全中文表达缺口并纠正必要的英文错误；原文合适时可以保持不变，有歧义时可以请求澄清。
- **⌃⌥D（Control-Option-D）**：结合实际采集到的上下文，解释选中的英文词句。上下文缺失或不完整时会标注；阅读解释不会修改原文。
- 光标或文本附近的不抢焦点卡片先显示请求进度，再原位展开原文、建议和差异。状态切换保持同一吸附边缘，并遵循系统“减少动态效果”设置。接受成功后在附近短暂反馈，错误通过菜单栏提示。部分编辑器只提供控件边界，因此卡片可能靠近输入区，而非精确光标位置。
- **⌃⌥↩（Control-Option-Return）** 或接受按钮应用建议；**Esc** 或 **⌃⌥.（Control-Option-Period）** 关闭建议。普通 Return、Tab 仍由编辑器处理。
- 写入前重新检查来源、焦点和选区，只执行一次原生粘贴；随后验证结果与光标，并按条件恢复剪贴板。可使用原编辑器的原生撤销恢复修改。
- 能读取基础富文本属性时尽量保留格式。TextEdit、Word、备忘录的普通正文遇到私有属性时，可使用带安全检查的纯文本降级，并显示格式限制；识别到结构化内容时拒绝此降级。复杂格式仍需按应用验证。
- 直接连接兼容 DeepSeek 的 Chat Completions 服务，可配置地址和模型，密钥存储于系统钥匙串。联网需明确开启；请求设有范围限制、取消、冷却和内存缓存。失败时不会自动付费重试，也不会静默切换到演示结果。
- 可开关的本地诊断日志不记录正文：开发版默认开启，正式版及未知构建类型默认关闭。每个通道最多保留五个 1 MiB 文件，保留期七天；不上传日志。

需要学习修改原因时，点击候选中的 **“为什么这样改？”**。成功接受后，可从菜单打开 **“最近一次建议…”**。解释按需查看，不影响直接接受；最近记录仅保存在当前会话内存中，不保存完整草稿。

## 本地体验

需要 macOS 14 或更新版本，以及已安装并选为活动工具链的完整 Xcode。

```sh
swift test --disable-sandbox
sh Scripts/build-local-app.sh development
```

从菜单栏退出旧进程，再打开 `.build/LingoMend.app`。进入 **设置 → 访问与应用**，允许 TextEdit 或开启其他应用的按需求助，并手动授予 macOS 辅助功能权限。重新构建的临时签名应用可能需要重新授权。

在 **模型服务** 中配置模型。连接测试会发送一次合成请求，即使普通联网未开启也可能产生费用。请勿将 API 密钥放入仓库。

将光标放在句中或选中文字，按 **⌃⌥L** 请求建议。核对后按 **⌃⌥↩** 接受，或按 **Esc** 关闭。选中英文后按 **⌃⌥D** 查看语境解释。需要恢复修改时，使用原编辑器的撤销命令。

## 产品与隐私约定

用户先表达，再主动求助。空闲时不读取草稿、不调用模型。辅助功能桥接层可能在本地读取聚焦输入框，以确定句子范围；外发文本有独立限制：当前句不超过 600 个 UTF-16 代码单元，明确选中的短段落不超过 1200，阅读选区不超过 1200，阅读总上下文不超过 2000。本地采集范围与网络发送范围分开控制。

不记录按键，不通过隐藏的复制操作采集文本，不监控剪贴板，不使用 OCR，也不自动续写尚未完成的观点。仅在明确接受建议时临时借用剪贴板，其内容不会发送给模型服务或写入日志。系统事件发送与剪贴板恢复无法组成原子操作；发送后结果不明确时会提示，不自动重试或撤销。模型响应的格式校验不能证明语义正确。详见 [安全边界](SECURITY.md)。

## 架构与贡献

使用 Swift 6.1、SwiftPM、AppKit 和 SwiftUI，无 Electron、内置大型模型或云端中转服务。

CoachCore 负责模型契约；MVPFlow 负责建议展示模型；PlatformBridge 负责辅助功能读取、范围判定和原生编辑；DiagnosticsCore 记录有限的过程事件；LearningCore 保留后续表达记录功能的基础。TypeTide 是独立研究的 MIT 参考项目，并非本项目底座。

贡献前请阅读 [AGENTS.md](AGENTS.md) 和 [CONTRIBUTING.md](CONTRIBUTING.md)。内部规划、运行日志、评测结果与验证记录仅保留本地，并由 Git 忽略。
