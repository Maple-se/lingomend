# Word 适配体验：始于 build 17，当前 0.5.3 / build 18

本版针对 Word 正文的两处采集差异：其页面文本控件可能把 `AXEnabled` 报为 false，
而自身仍可原生编辑；阅读选区可能没有 `AXSelectedText`，但有同一控件的正文和数字选区。
写作仅在该正文控件同时声明正文与选区可设置时开放，接受前仍逐次核对焦点、原文和范围。
阅读后备只按实际选区截取，不按词语搜索位置。写作仍保留 65,536 个 UTF-16 单位的
正文上限；阅读的完整正文后备也只用于这一上限内的文档。
Word 若返回无法转换的私有富文本属性，仅对不含附件、链接和列表结构的目标片段使用
普通文本原生粘贴；接受后会提示“格式未保证”。结构内容仍拒绝写回。

## 在合成文档中验收

1. 从 LingoMend 菜单栏图标退出旧版，打开 `.build/LingoMend.app`，确认菜单显示 `0.5.3 (build 18)`。
   确认设置中的“允许其他应用中的按需写作与阅读”已开启；如系统提示权限失效，手动重新授权。
2. 在 Word 新建普通空白文档，输入以下两行。不要用已有工作文档或含敏感内容的文件。

```text
I very like 这个方案.
The current flows through the coil.
```

3. 只选中第二行的 `current`，按 ⌃⌥D。阅读解释应按整句语境说明“电流”；文档不得变化。
4. 只选中第一句，按 ⌃⌥L。核对建议后，松开按键，再按 ⌃⌥↩ 接受。
   第二行必须不变；按一次 ⌘Z，第一句应恢复。请勿在未核对建议时接受。
5. 把光标放在第一句 `very` 中间，不选文字，按 ⌃⌥L。候选范围应是第一句，
   而不是整篇文档；接受后再按一次 ⌘Z 验证。
6. 可选：在预览显示后先改动第一句或切到另一文档，再尝试接受。旧建议应被拒绝，
   不得写到新位置。

反馈请给出 Word 版本、选词解释、选句候选、接受、一次撤销、光标模式各项是否成功，
以及界面上的错误提示。不要发送正文或原始运行日志。开发日志在本地记录焦点角色、
选区长度、可写能力与拒绝原因，不记录文档内容，且继续被 Git 忽略。

这组步骤针对普通正文。批注、修订模式、表格、页眉页脚、只读/受保护文档和复杂混合
格式尚无真实验收；这些控件若无法满足同一焦点与范围重验，应拒绝写回。
