# 模型服务体验步骤

本页仅使用合成文本。不要提交密钥、真实草稿或带密钥的截图。

## 配置服务

1. 打开 `.build/LingoMend.app`，从菜单栏 LingoMend 图标进入“设置…”。
2. 在“访问与应用”中勾选 TextEdit，检查辅助功能权限；需要授权时点“打开系统设置”。
3. 在“模型服务”中保留 DeepSeek 预设或填写自己的安全服务地址和模型 ID，输入 API Key。
4. 点“测试连接（合成文本）”。它只发送 `This works 轻载条件下.`，可能产生少量费用。
5. 测试通过后开启“使用配置的模型服务”，点窗口底部“保存设置”。密钥保存在 macOS 钥匙串。

测试失败时检查设置页状态：凭据拒绝、余额不足、限流、地址或模型错误分别处理。服务失败不会冒充本地固定样例结果。

## 在 TextEdit 中写作

1. 新建不含个人信息的 TextEdit 文档，输入 `This works 轻载条件下.` 或 `I very like 这个方案.`。
2. 把光标留在目标句中，按 **⌃⌥L**。核对候选卡片中的“原文”“建议”和“修改”。
3. 同意建议时按 **⌃⌥↩** 或点“接受”；在 TextEdit 中按 **⌘Z** 检查撤销。
4. 再次求助时，按 **Esc** 或 **⌃⌥.**，或点“收起”，检查原文保持不变。
5. 选中英文词句后按 **⌃⌥D**，查看只读语境解释；点“关闭”返回编辑器。
6. 请求期间修改原文、移动选区或切换应用，旧请求和候选应失效。普通输入、Return、Tab 和输入法组词仍由 TextEdit 处理。

网络关闭时仅固定合成样例有演示结果。开启模型服务后，每次快捷键请求可能产生费用；已发出的请求即使在客户端取消，服务端仍可能处理。

## 删除密钥

在“模型服务”点“删除当前地址的已存密钥…”，确认后点“保存设置”。此操作只删除当前服务地址对应的钥匙串条目，并关闭模型服务。

当前跨应用写作与阅读的操作和限制见 [T3 体验步骤](t3-global-experience.md)。
