# 阶段 2：真实 DeepSeek API 体验

这份文件是公开的操作步骤，不是验证结果日志。请不要提交密钥、账户信息、真实草稿或带密钥的截图。

## 1. 打开新版并配置

1. 从 LM 菜单退出旧版，打开项目 `.build/LingoMend.app`（0.2.0 / build 3）。
2. 打开 **LM → 设置**；先保持伴随候选和跨应用接受关闭。
3. 保留预设：API Base URL `https://api.deepseek.com`，模型 ID `deepseek-flash`。
4. 在 **新 API Key** 输入你自己的 DeepSeek 密钥，不要发给开发助手，不要写到项目文件。
5. 点击 **测试连接（合成文本）**。此按钮仅向显示的地址发送
   `This works 轻载条件下.` 的小范围样例，可能产生少量费用；不读取其他应用。
6. 若连接/格式检查通过，勾选 **使用配置的模型服务**，点击 **保存设置**。
   密钥保存在 macOS 钥匙串，保存后输入框会清空；留空再次保存会保留已存密钥。
   系统若询问访问钥匙串，请自行确认是否允许当前 LingoMend。

测试失败时：401/403 检查密钥；402 检查余额；429 稍后重试；其他 HTTP 错误核对地址/模型。
空内容、截断、非法 JSON 或不安全候选会被拒绝，不会修改原文或冒充本地演示结果。
客户端候选上限为 12 秒；网络慢可反馈超时情况，不要求反复点击。

## 2. 先在 app 自己的输入体验里用（无需辅助功能权限）

1. 打开 **LM → 打开输入体验**，确保状态显示 `DeepSeek API · 联网`。
2. 用原来的输入法逐行尝试以下合成句子，中文提交后把光标留在附近，停顿：
   - `This works 轻载条件下.`
   - `We need to 提高效率.`
   - `Please confirm 在周五之前.`
3. 观察短候选是否贴近光标、是否适合原句。不同表达和服务返回 `abstain` 都是允许的；
   不要求模型逐字给出固定答案。没有候选时看编辑器底部状态。
4. 用 **⌃⌥↩** 接受，继续写作；**⌘Z** 检查原生撤销。
5. 再产生一个候选，用 **⌃⌥K** 或“学习”主动展开解释。
   解释应只在这时加载，可关闭取消，可主动保存表达；表达列表属于下一阶段。
6. 请求中继续输入、移动光标或切到其他 app，旧候选不应稍后突然回来或写入。
7. 中文组词期间、普通 Tab/Return 不应被 LingoMend 接管。

联网后，只有中文占位及左右各最多 200 个 UTF-16 单位的当前范围文本发送给服务，
主动学习另附固定候选。不主动提交整篇文档；短句/短输入框可能全部落在该范围内。
没有聊天历史、学习记录上传或云中转。
候选请求受 3 秒启动间隔和短期内存缓存控制；不保证每次停顿都即时发出新请求。
语义准确性仍需自己判断，格式校验不等于译文正确。

## 3. 离线与取消检查

- 关闭 **使用配置的模型服务** 并保存。状态切回本地演示；仅“轻载条件下”样例可用。
  其他中文不会伪装成真实 AI 建议。
- 再开启时无需重复填同一地址的密钥。切换地址不会复用原地址密钥，并清空未保存的密钥输入。
- 在设置页点测试后点“取消测试”，或修改设置/关闭窗口，旧测试结果不应覆盖新状态。
- 删除密钥时先关闭模型服务并保存。删除的是当前显示地址的钥匙串条目，其他地址不变。
- 已发出的请求即使客户端取消，服务端仍可能处理和计费。

## 4. 可选跨应用体验（不是本轮必测项）

愿意测试时才在设置中开启伴随并勾选 TextEdit / Safari。网络模式下其候选可自动上传
小范围文本；浏览器授权不是网站白名单，请勿在真实私密会话中使用。
仅用合成文档，跨应用接受仍实验性且默认关闭，可先只看候选。
临时签名构建可能需要手动重新添加辅助功能权限。外部输入法组合态、原生撤销与兼容性仍待反馈。

## 建议反馈

先告诉我四件事即可：连接是否成功、候选延迟大致几秒、表达是否自然、是否打断输入。
若有问题，提供合成句子、状态提示和复现步骤即可；不提供密钥、真实草稿或敏感日志。
接到反馈后再进入输入适配/接受修复或阶段 3 表达库，不自动继续下一阶段。
