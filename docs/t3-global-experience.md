# T3 全局写作和阅读体验版（0.5.1 / build 8）

## 开始使用

1. LM 菜单退出旧进程，打开 `.build/LingoMend.app`；菜单版本应是 0.5.1、T3 开发版。
2. 设置中开启“允许其他应用的按需求助”，保存。若 macOS 要求，手动重新授权辅助功能。
3. 已有 API 地址、模型、钥匙串密钥与联网选择保留。关闭联网时只有固定合成样例；
   开启后快捷键会发送有界文本并可能产生费用，不会自动分析输入。

## 优先体验：在日常应用里试同一小组动作

从 TextEdit 开始，然后按自己实际使用顺序试 Safari 输入框、备忘录、微信草稿、
VS Code 的合成文本/注释、Codex 的合成输入草稿。不要求一次测完；使用已安装的应用即可。

1. 写 `I very like 这个方案.`，把光标放在 very 中间，按 ⌃⌥L。
   应显示 `I really like this approach.` 的建议，当前句包含光标两侧，焦点仍在输入位置。
2. 松开快捷键后按 ⌃⌥↩ 接受；确认只改此句。按 ⌘Z 一次，确认原文恢复。
   微信/Codex 应只修改草稿，消息不发送。普通 Return 仍由原应用处理。
3. 把下面两行全选后按 ⌃⌥L，确认标为“所选短段落”，接受后两行都改好，前后其他内容不变。

```text
I very like 这个方案.
This works 轻载条件下.
```

4. 发起求助后改动文本、移动光标或切换应用，确认旧候选取消，不误写另一个位置。
5. 先复制一个普通测试标记，再接受一次；随后手动粘贴到空白测试处，确认原剪贴板恢复。
   测试时不要用真实敏感内容。复杂文件/承诺型剪贴板会拒绝接受，可换普通文本再试。

TextEdit 基础格式沿用 T2；其他应用若只提供普通文本能力，粘贴后样式由编辑器处理。
有些编辑器不支持设置范围，可先明确选中需要处理的词句再求助。

## 阅读

在网页、文字 PDF（预览和 Safari）、笔记、可选择消息或编辑器里选中英文词/句，按 ⌃⌥D。
应给出语境词义、读取到的所在句和中文解释；没有替换按钮。Esc / ⌃⌥. 关闭。
拿不到上下文时必须明确提示，只给常见含义；扫描 PDF 当前不做 OCR。

关闭联网也可在 TextEdit 测下面两句：分别选中 current。第一处应是“电流”，第二处“当前的”。

```text
The current flows through the coil.
This is our current plan.
```

## 反馈只需这些信息

- 应用和输入区域，例如“Safari 普通 textarea”“微信聊天草稿”“Codex 输入框”。
- 写作：候选/接受/一次撤销分别是否成功，是否仍在正确草稿内。
- 阅读：是否读到选词、所在句是否对应；若无上下文，是否如实提示。
- 若失败，提供界面提示和使用的是光标模式还是选区模式即可。不要公开真实原文或原始日志。

自动测试覆盖范围、请求、取消、纯/富文本原生编辑与剪贴板边界。上述真实应用兼容性仍由
体验结果确认；此表没有预填“通过”，读不到可访问控件时也不会声称已经适配成功。
