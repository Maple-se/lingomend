# T3 收尾：当前体验与回归

当前版本、支持范围和遗留项统一见 [交付状态](status.md)。本页是当前操作入口；旧 T1/T2/build 16 文档只保留历史案例。

## 准备

1. 从菜单栏 LingoMend 图标退出旧进程，打开 `.build/LingoMend.app`，核对菜单版本与状态页一致。
2. 设置 → 访问与应用，勾选 TextEdit；其他应用需开启“允许其他应用中的按需写作与阅读”并保存。
3. 检查辅助功能权限。临时签名更新后若授权失效，在系统设置移除旧条目，重新添加同一路径的 app 并开启。
4. 已有地址、模型、密钥与联网选择沿用。关闭模型服务只支持固定样例；开启后快捷键会发送有界文本并可能收费。接受、撤销和取消不额外调用模型。

## 代表性应用：每次只测一个合成区域

建议 TextEdit → 备忘录普通正文 → Codex 输入草稿；再按实际使用回归 Word、VS Code、Safari。
微信暂未解决，按用户决定延期，本轮无需测试。Word 复杂区域和文字 PDF 保留后续兼容性任务，不作为本次全量门槛。

在可丢弃的普通文本区域输入：

```text
I very like 这个方案.
The current flows through the coil.
```

1. **光标模式**：光标放在 very 中间，按 ⌃⌥L。候选原文应是完整第一句；不读取下一句作为修改目标。真实模型措辞可有合理变体。
2. **接受与撤销**：核对建议后松开按键，按 ⌃⌥↩ 或点“接受”。只改第一句，第二句不变；按一次 ⌘Z 恢复原文。
3. **选区模式**：只选第一句再求助、接受、撤销；再只选第二句的 current，按 ⌃⌥D，应按语境解释为“电流”。阅读不得改动原文或剪贴板。
4. **取消与过期**：候选出现后按 Esc / ⌃⌥.，确认原文不变。再次求助后改动正文、移动选区或切到另一输入框，旧候选应失效，不能写入新位置。
5. **剪贴板与格式**：先复制普通标记，再接受一次；手动粘贴到空白测试处应仍是原标记。遇到文本回退提示时检查格式；附件/链接/列表等复杂结构不在普通正文保证范围。

Codex 若提示没有可定位编辑器，请先点击实际输入区再请求，保留提示与版本反馈；不要把应用没有暴露焦点误记为用户没有输入。
备忘录重点复测此前普通正文格式拒绝的场景；不要为强行通过而删除真实笔记结构。

## 显式短段落与基础格式

可选：明确选中以下两行后按 ⌃⌥L，候选标为所选短段落，保持换行与句外内容；接受后一次撤销。

```text
I very like 这个方案.
This works 轻载条件下.
```

TextEdit 基础字体/粗斜体、下划线与颜色用 [T2 历史案例](textedit-t2-experience.md)回归。其他编辑器的原生粘贴和样式由实际控件决定，回退为普通文本时会明确提示格式未保证。VS Code 只保留一个光标；多光标/多选区应被拒绝。

## 阅读与界面

阅读范围和应用状态以状态页为准；网页或文字 PDF 未取得完整语境时应如实标注，不用常见含义冒充准确语境词义。扫描 PDF 不做 OCR。
候选不抢编辑焦点，长内容可滚动；设置分常规、访问与应用、模型服务、本地诊断。
可选用 VoiceOver、暗色/高对比度、多显示器边缘检查可读性与定位，这些检查通过前不声明全部无障碍/显示器场景已验收。

反馈给出应用/输入区域、当前版本、光标或选区方式，以及范围/候选/接受/一次撤销/取消分别是否正确。失败时给短提示即可，不上传私人正文或原始日志。兼容性结论集中更新状态页。
