# ADR 0005：TextEdit 的单次原生接受

日期：2026-10-09。状态：实现采用；真实 TextEdit 验收待完成。

## 授权与范围

用户已明确允许：仅在接受建议时，临时借用系统剪贴板完成 TextEdit 原生编辑。
不观察剪贴板，不将其内容发给模型，不保存到磁盘；不扩展到其他应用或后台自动接受。

## 实现

- `SentenceEditPlan` 重解析原快照的句子范围与用户授权边界，以完整字符的共同前后缀缩小为一个连续编辑范围。
  多缺口之间的未变文字保留样式后随同一次粘贴；纯删除包含一个目标内未变邻字，避免空剪贴板无效粘贴。
- 接受前新读快照，核对应用、元素身份、完整文本、版本指纹和原选区；不能搜索相同文字去另一个位置替换。
- 接受时读目标的 AX attributed string，将 AXFont 字典、颜色、下划线等转换为原生属性。字符差异保留未改样式，新增文字继承修改位置样式。
  未暴露字体或包含未知/复杂属性时拒绝，不擅自改为纯文本。AX 未暴露的高级排版不能据此认证支持。
- 原剪贴板按项/类型保存数据，使用本次 UUID 标记和 `changeCount` 判断恢复所有权；不可还原、文件承诺或超限内容拒绝使用。
- 松开修饰键后，重新检查源快照，设置局部选区，再检查实际源/选区/剪贴板，向目标 PID 发一次 Command-V。
  不设置整个 AXValue，不向另一应用投递，不激活文档，不连续模拟逐字输入。
- 发送后限时检查目标完整文本与预期一致；仅在仍是本次粘贴光标位置时调整到修改后目标末尾。不能确认就报告，不重试或自动撤销。
- 原生粘贴使用目标编辑器的撤销链，不在 LingoMend 中维护另一个恢复全文的“伪撤销”。
- 请求和候选期间的 AX 变化通知仅用于检查失效；相同快照的重复通知不取消。没有候选时不注册接受键。
- 取消清除请求/候选/接受键。Escape 观察器仅在请求或候选活跃时存在，不读输入字符、不吞事件；普通编辑与 IME 处理保留。
- UI 显示实际运行版本，显式操作的状态与错误以短暂非激活提示展示；无空闲主动建议。应用正常退出等待接受和剪贴板清理。

## 验证与限制

用命名测试剪贴板、隐藏原生 NSTextView 与可注入驱动覆盖单次粘贴/撤销、基础格式与拒绝分支。
这不是外部 TextEdit 的真实链路认证；交付后由用户按 [T2 体验步骤](../textedit-t2-experience.md) 验收。

剪贴板及键事件 API 没有跨进程原子事务：检查后仍可能发生焦点/复制竞态、事件延迟，崩溃也可能中断清理。
不宣称绝对无误写或任意格式保持；无法确认发送后的结果时明确提示原文可能已变化。
第三方剪贴板历史和系统同步可能记录临时内容，恢复不能删除那些副本。

AX 字体接口由 find-docs / Context7 核对。CG 键事件查询未命中文档索引，改以当前 SDK 声明及编译器核对接口；实际跨进程行为仍需验收。相关官方文档：
[AX 字体属性](https://developer.apple.com/documentation/applicationservices/kaxfonttextattribute)、
[目标进程键事件](https://developer.apple.com/documentation/coregraphics/cgevent/posttopid(_:))、
[NSPasteboard](https://developer.apple.com/documentation/appkit/nspasteboard)。
