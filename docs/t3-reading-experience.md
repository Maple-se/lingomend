# 选区阅读补充案例

当前启动、版本与应用状态统一见 [当前体验](t3-global-experience.md)和[交付状态](status.md)。本页只补充阅读案例，不维护独立版本或阶段计划。

## 准备

1. 从 LingoMend 菜单栏图标退出旧进程，打开本次构建的 `.build/LingoMend.app`。
2. 若系统要求，手动重新授予该 app 辅助功能权限。
3. 菜单栏图标 → 设置…：开启“允许其他应用中的按需写作与阅读”，保存。模型配置沿用已有值。
4. 不联网时只能解释下面两个 current 合成样例；真实内容需要开启模型服务，每次请求可能计费。

## 两分钟基础检查

在 TextEdit 放入以下两句，分别选中其中的 current，再按 ⌃⌥D：

```text
The current flows through the coil.
This is our current plan.
```

- 第一处应是“电流”，第二处是“当前的”，并给出各自所在句的中文解释。
- 卡片显示的原文语境应属于当前选词，不应混入另一句；没有替换/接受按钮。
- Esc 或 ⌃⌥. 关闭。选区/焦点变化使旧结果失效，不会继续显示另一个位置的解释。
- 原文、选区和剪贴板不应因读取/解释发生变化。

## 按实际使用顺序体验，无需一次测完

| 场景 | 操作与关注点 |
| --- | --- |
| Safari 网页 | 选英文词，再选完整句；看是否取得正确所在句，点击链接前先关闭解释 |
| 文字 PDF（预览、Safari） | 选择可复制的英文词句；检查换行/连字符与语境；扫描图片不支持 |
| 备忘录 | 在合成笔记中选词，确认词义与所在句对应 |
| 微信 | 暂未解决并延期；本轮不要求测试 |
| VS Code | 英文注释或独立合成文本中的词句；不是让模型解释或改写代码 |
| Codex | 合成输入草稿或可选择的英文消息；不发送、不修改内容 |

若显示“未读取到上下文”，检查其是否只提供常见词义、不编造所在句。
若完全读不到选区，记录应用名、输入区域/只读区域、是否文字 PDF，以及界面提示即可；
不要粘贴敏感原文、密钥或原始诊断文件到公开 issue。

有模型服务时可再选一个完整句子，看中文解释是否保留否定、可能性、数值和作者立场。
真实模型含义质量由用户判断；读懂选区与成功发出请求是不同的验收项。
