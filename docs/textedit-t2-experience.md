# TextEdit T2：接受、取消、原生撤销

版本：0.4.0（build 5）。实现已交付；真实 TextEdit 验收待用户试用。

## 启动

1. 从旧 LM 菜单退出应用，再打开项目 `.build/LingoMend.app`。LM 菜单应显示 `LingoMend 0.4.0 · TextEdit T2`。
2. 设置中允许 TextEdit，保留已有模型配置。无需重填钥匙串密钥。
3. 若提示缺少辅助功能权限，手动移除旧授权条目、重新添加同路径应用并开启，再重启应用。临时签名重建可能改变权限身份。
4. 建议先关闭网络，用下面的固定样例体验编辑链路。也可保留真实模型：每次求助可能计费，但接受、取消和撤销不额外调用模型。

求助 `⌃⌥L`；候选出现后 `⌃⌥Return` 或点“接受”；`Esc`、`⌃⌥.` 或点“取消”关闭候选。
等待建议时也可用取消键。Esc 只被观察，不吞掉 TextEdit/输入法的原有事件；普通 Return/Tab 不被接管。
接受键在候选存在时才注册。按下组合键后松开修饰键，应用再发送一次原生粘贴。

## 六项基本验收

仅用新建的合成文档，接受后先不要继续输入，先检查结果和撤销。

| 项目 | 操作 | 检查 |
| --- | --- | --- |
| 整句接受 | 写 `First stays. This works 轻载条件下.`，光标在第二句，求助并接受 | 第一整句不变；第二句自然英文；光标位于修改后目标末尾，可直接继续写 |
| 一次撤销 | 接受后保持 TextEdit 前台，按一次 `⌘Z` | 恢复此次修改，不需要多次撤销；可再用 `⌘⇧Z` 检查重做 |
| 选区边界 | 写 `I am 负责 this project.`，只选“负责”后求助并接受 | 只有选区替换为 `responsible for`；左右文字不变 |
| 取消 | 求助后按 Esc 或点取消，再按普通 Return/Tab | 原文不被修改；普通编辑键仍由 TextEdit/输入法处理 |
| 过期候选 | 出现候选后继续输入、移动光标、切另一合成文档或切其他应用 | 旧候选关闭，不能写到新位置；不自动再发模型请求 |
| 剪贴板恢复 | 先复制合成标记 `CLIPBOARD_BEFORE`，再完成一次接受；在另一空白测试文档手动粘贴 | 粘贴的仍是标记，而不是模型建议 |

## 基础富文本验收

新建富文本文档，写 `We need 降低损耗 without 增加成本.`。
将“降低损耗”设为粗体、18 号、红色，将 `without` 设为下划线，将“增加成本”设为斜体。
求助并接受：未改的 `without` 保留下划线；新英文继承对应修改位置的基础字体/样式。
然后只按一次 `⌘Z`，检查原文和原样式同时恢复。句外文字及格式不应改变。

本轮采用局部字符差异保留未改样式；插入文本继承替换位置的样式。目标是基础格式，不是任意复杂排版。
链接、附件、上下标、未知 AX 布局属性或可识别的表格/列表不支持时拒绝粘贴，不降级为纯文本或覆盖整框。

## 失败与并发边界

- 原文、聚焦元素、选区和版本指纹在接受前重验。粘贴前设置局部范围后再读一次，确认实际选中范围。
- 剪贴板只在接受时读取；原内容仅在内存保存，不提供给模型、日志或学习记录。多项/多类型原始数据按项保存，限 32 项、每项 64 类型、总计 4 MiB；文件承诺或无法取到的数据拒绝使用。
- 恢复前检查本次标记和 `changeCount`；检测到其他复制则不覆盖。系统剪贴板没有跨进程原子比较/交换，不能承诺消除所有并发竞态。
- 粘贴仅发送到核验的 TextEdit 进程，不主动切换应用。系统事件投递与控件写入并非原子操作；发送后约 1.2 秒内核对结果，AX 调用延迟可能延长总等待。
- 发出粘贴后若结果未确认，提示检查原文/必要时撤销；不自动重试，不自动撤销，不伪称“原文一定未变”。系统繁忙时也可能晚收到事件。
- 正常退出等待当前粘贴核验与剪贴板清理；强制退出/崩溃无法保证恢复。第三方剪贴板历史或系统剪贴板同步可能记录临时内容，恢复当前内容无法清除那些副本。
- 若中文输入法仍在组词，先提交组词再求助/接受。外部 AX 没有统一可靠的组合态接口，真实输入法体验属于本轮人工验收。
