# TextEdit 原生编辑补充案例（始于 T2）

本页保留 T2 的编辑与格式验收案例。当前版本与支持范围见 [状态页](status.md)，准备步骤及快捷键见 [当前体验](t3-global-experience.md)，有效阶段顺序见 [开发计划](development-stages.md)。学习解释与最近建议回看现归 T4.1。

## 原生编辑

| 场景 | 操作与验收目标 |
| --- | --- |
| 整句 | `First stays. This works 轻载条件下.`，光标第二句求助并接受；第一句不变，光标回到目标末尾 |
| 撤销 | 接受后在原编辑器按一次 ⌘Z，恢复此次修改；可选检查重做 |
| 精确选区 | `I am 负责 this project.` 只选中文；仅替换选区，不重复前后文 |
| 取消 | 请求或候选期间按 Esc/⌃⌥.，原文不改；普通 Return/Tab 仍由原编辑器处理 |
| 过期 | 候选出现后输入、移选区或切文档；旧建议失效，不自动重新生成或写到新位置 |
| 剪贴板 | 先复制普通测试标记，再接受；之后在空白测试处手动粘贴仍应是原标记 |

## 基础格式

在新建合成富文本文档写 `We need 降低损耗 without 增加成本.`，将降低损耗设为粗体、18号、红色，without 设为下划线，增加成本设为斜体。接受后核对未改文字样式与插入文字的继承，再一次撤销检查文本和样式恢复。

这是基础格式验收目标，不是任意复杂排版保证。当前策略按 [ADR 0008](adr/0008-global-writing-and-selected-passages.md)：基础属性优先转换为 RTF；普通正文的非结构性未知属性可受限回退为普通文本并提示格式未保证。可识别链接、附件、上下标、列表/表格拒绝该回退，不覆盖整框。

## 并发与失败

原文、控件、选区和版本指纹在接受前重验；设置局部选区后再读一次。剪贴板按项/类型保存在内存，恢复前检查所有权与 changeCount，检测到新复制就保留它。

发送后结果未确认时不得自动重试或自动撤销。正常退出等待当前核验/清理，崩溃、强制退出及系统延迟仍有限制；第三方剪贴板历史可能记录临时内容。先提交输入法组词再求助。

隔离 NSTextView/命名剪贴板自动检查与真实 TextEdit 验收分开。反馈文本范围、接受、一次撤销、格式、剪贴板及短提示；私人操作记录只留本地，产品支持结论集中维护状态页。
