# 产品有效需求与待办

更新：2026-10-27。本页维护当前产品契约；阶段见 [开发计划](development-stages.md)，交付/兼容性见 [状态页](status.md)。早期 V0.1 方案和 TextEdit 调研为需求来源，后续用户确认优先，旧阶段编号不再同时执行。

> The goal is to need us less.

用户先写自己的英文，不会的部分可用中文占位；保留现有输入法，快捷键请求语言帮助，明确接受才修改。帮助应保留作者事实、观点、语气与可用措辞；学习是主动分支。

## 当前契约

- ⌃⌥L：无选区按当前完整句理解；显式选区是编辑边界，所在句可作为只读语境；支持明确选择的短段落。
- 中文补缺与必要英文修正一起完成，不拘泥于只替换中文；自然正确的原文应返回无需修改。未完成的观点留给作者。
- ⌃⌥D：只读解释选中词句在实际取得语境中的含义；缺少上下文时明确提示，不编造所在句。
- 本地决定范围与坐标；外发有限文本，模型不指定应用、控件或工具动作。接受前重验，一次原生粘贴，结果不明不自动重试。
- 空闲不采集写作；无键盘内容记录、隐藏复制采集或剪贴板监控。只在接受期间临时借用剪贴板。
- 日志只含固定事件与有限结构指标；正文、凭据、网络内容和剪贴板不进日志；日志本地保存且被 Git 忽略。
- 当前句预算 600 UTF-16，显式选段 1200，阅读选区 1200/合计语境 2000。超限提示，不静默扩大到整篇。

## 质量与验收

保留否定、不确定性、数字、单位、术语、引文、专名与作者情绪；不增加理由、承诺、结论或通用 AI 文风。
非 prose 检测不是完整代码解析器；无符号代码可能原样保留，不能据此宣称支持代码编辑。机器约束只能验证结构与部分锚点，不能证明语义保真；用 [合成质量案例](quality-review.md)和用户实际反馈验收。
一次接受只改授权目标；源内容、选区或焦点变化后旧候选失效；一次原生撤销、格式和光标行为按实际应用确认。

学习收藏只保存必要表达，不保存全文。独立使用证据仅来自后续主动调用、模型处理前的草稿；系统无法从短语命中可靠区分手写、粘贴或记忆来源，界面只呈现证据与谨慎描述。
周报、CEFR/等级、自动评分、间隔复习、Windows 扩展是后续探索，不进入 T3 收尾或 T4.1。T4.1 的解释请求不自动触发，只在用户点击“为什么这样改？”时调用；解释失败仍保留接受入口。

原始文档中的两种改写档位、场景选择、统计和成长指标是规划目标，并非当前支持声明。本文表格中的未交付项保留到后续明确决定，不因阶段调整而丢失。

build 20 用户反馈要求保留输入法和快捷键求助的按需边界，同时减少菜单栏结果卡片对写作的打断。正常候选不应主动续写或自动联网；就地卡片和句子切分优化属于后续体验与兼容性工作，不能倒推为当前版本已实现。
