# 阶段 1 体验步骤

本页仅为可公开的合成测试步骤，不记录个人验证结果。
阶段 1 为交互骨架：仅识别固定样例“轻载条件下”，不接入真实模型。

## 先体验主交互（无需辅助功能权限）

1. 从旧版 LM 菜单退出应用，然后打开本次构建的 `.build/LingoMend.app`。
2. 点击菜单栏 LM → **打开输入体验**。保留原有中文输入法，无需切换到新的输入源。
3. 编辑器里有 `This works 轻载条件下.`。把光标放在句末，停顿约 1 秒。
   预期光标附近出现简短候选 `under light-load conditions`，不自动打开解释窗。
4. 按 **⌃⌥↩**（Control + Option + Return），或点候选上的“接受”。
   预期仅中文占位变为英文，结果为 `This works under light-load conditions.`。
   继续输入 ` More text.`，观察是否可以顺畅续写。
5. 按 **⌘Z** 撤销刚刚的输入/接受。注意刚输入的续写可能先被撤销；记录候选接受
   是否能单独撤销，以及光标是否合理，不预先宣称这项体验通过。
6. 恢复样例，候选出现后按 **⌃⌥K** 或点“学习”。这时才应出现原文、建议与解释。
7. 候选出现后直接继续打字或移动光标，旧候选应收起，不应自动应用。
   **⌃⌥.** 主动收起候选；普通 Tab、Return、中文组词键仍属于原有编辑器/输入法。
8. 用自己的输入法重新输入样例中的中文，观察组词尚未上屏时是否出现候选。
   本地体验页检查 `hasMarkedText`，不应在组词期间生成候选。

优先反馈：候选是否遮挡、是否抢焦点、接受是否顺手、停顿时机是否打断思路。
快捷键只是阶段 1 的低侵入原型；是否改成更顺手的接受方式由体验反馈决定。

## 可选：TextEdit 跨应用候选

1. LM → 设置，勾选“启用伴随候选”和 **TextEdit**，保存设置。
   暂不勾选 Safari，不打开实验性接受。
2. 系统设置中手动为本次 `.build/LingoMend.app` 开启辅助功能权限。
   本地临时签名构建变化可能让旧授权失效；必要时移除旧条目，再添加当前 app。
   授权后重新保存设置，或重启应用。
3. 在独立、未含个人信息的 TextEdit 纯文本窗口输入：

   ```text
   This works 轻载条件下.
   SECOND_LINE_MUST_STAY_UNCHANGED
   ```

4. 光标停在第一行句末，不选中文字。预期候选自动靠近光标，不先按 ⌃⌥L。
   自动候选有节流，可能需要约 1–3 秒。若没有候选，可按 ⌃⌥L 手动重试，并查看
   LM 菜单状态。读取/定位不支持时不会退化为居中大预览。
5. 默认跨应用候选只有复制/学习，不写入文档。继续输入、移动光标、切换输入框
   或切走应用，确认旧候选不再可用；第二行不能被候选处理。

跨应用中文组词状态和通知送达并非 AX 通用保证，若体验异常请反馈应用和输入法。
实验性接受及原生撤销作为下一阶段的重点；当前先用本地体验页评价主交互。
